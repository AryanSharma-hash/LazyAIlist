# 🦥 LazyAIList

> **The lazy person's guide to AI tools.** A beautifully curated, blazing-fast, multilingual directory featuring 80+ top-tier AI applications to help you work smarter, not harder.

LazyAIList is a lightweight, zero-dependency Multi-Page Application (MPA) simulation built using vanilla JavaScript and Tailwind CSS. It is fully responsive, optimized for Google AdSense monetization, and built with privacy standards ready for production.

---

## 🌟 Key Features

*   **🌍 Multi-Language Support (i18n):** Seamlessly switches between English, Spanish, French, and Hindi natively without reloading.
*   **📂 Multi-Tag Filtering & Instant Search:** Instantly filter tools across categories (LLMs, Video Editing & VFX, Game Dev, Students, Image Removers) with an animated visual loader.
*   **📱 Sim-MPA Architecture:** Clean URL hashing (`#about`, `#privacy`, `#terms`) built into a single file for fast execution.
*   **⚖️ Google AdSense Ready:** Pre-built responsive banner layout with fixed-width calculation safeguards (`availableWidth=0` patch) and an optimized privacy policy template.
*   **🍪 Privacy Compliant:** Features a smooth, sliding cookie consent banner that caches preferences locally.
*   **🌙 Persistent Dark Mode:** Automatically syncs with user system preferences or saves manual preferences across sessions.

## 🚀 How to Launch This Live on GitHub Pages (Free)

Since this website is built entirely on a static architecture, you can host it live on the web through **GitHub Pages** in under a minute without paying a cent.

1. **Upload your code:** Push your `index.html` file directly to the main branch of your GitHub repository.
2. **Go to Settings:** In your repository tabs, click on **Settings** (the gear icon ⚙️).
3. **Navigate to Pages:** Scroll down the left sidebar menu and click on **Pages**.
4. **Build and Deployment:** Under the "Build and deployment" section:
   * Set **Source** to `Deploy from a branch`.
   * Under **Branch**, select `main` (or `master`) and set the folder to `/ (root)`.
5. **Save:** Click the **Save** button.

Give GitHub about 30 seconds to run its action runners, refresh the page, and you will see your live deployment link at the top (e.g., `https://yourusername.github.io/your-repository-name/`).
